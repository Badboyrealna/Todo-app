# To-Do List App (Java)

A beginner-friendly console To-Do List application written in Java. It runs in the terminal and lets you manage daily tasks with a simple menu.

## Features
- Add new tasks
- View all tasks
- Mark tasks as done
- Delete tasks
- See your progress as a percentage
- Input validation, so wrong input doesn't crash the program

## Tech
- Language: Java (JDK 8 or newer)
- No external libraries needed

## How to Run

```
git clone https://github.com/Badboyrealna/Todo-app.git
cd Todo-app
javac TodoApp.java
java TodoApp
```

## What I Learned
- Using classes and objects (the `Task` class)
- Working with `ArrayList`
- Handling user input with `Scanner`
- Using loops, `switch`, and exception handling
